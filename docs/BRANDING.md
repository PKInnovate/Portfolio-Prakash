# Brand Guidelines

## Visual Philosophy
The Prakash brand is built on **Visionary Minimalism**. It targets high-level decision-makers, investors, and elite researchers. The aesthetic must remain clean, dark, and professional at all times.

## Color Palette
Defined in `src/css/variables.css`:
- **Primary Background**: `#0d0d0d` (Deep charcoal/black)
- **Primary Text**: `#f8f8f8` (Off-white for readability)
- **Accent Color**: `#3b82f6` (Innovation Blue)
- **Secondary Background**: `#1a1a1a` (Section separation)

## Typography
- **Headings**: `Outfit` (Modern, geometric sans-serif)
- **Body**: `Inter` (High-readability sans-serif)

## Spacing
- Maintain generous whitespace (8rem vertical padding between major sections).
- Use the `container` class (max-width: 1100px) for all content alignment.
